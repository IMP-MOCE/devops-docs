# Журнал типовых инцидентов

| Инцидент | Наблюдаемый признак | Первичный источник диагностики |
| --- | --- | --- |
| Неиспользуемая переменная | Проверка `pylint` в PR не пройдена | Журнал шага Static analysis |
| Недостаточные права публикации | `build` успешен, `deploy` не получает OIDC-токен | Журнал deploy-pages и блок `permissions` |
| Битая ссылка | `mkdocs build --strict` завершается ошибкой | Журнал шага Build documentation |
| Старая версия после успешного деплоя | В браузере отображается прежняя версия | URL окружения, маркер сборки, кэш браузера |

## Правило разбора

Укажите симптом, затронутый компонент, доказательство из журнала, причину,
исправление и проверку восстановления.
