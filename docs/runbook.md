# Эксплуатация

## Штатная публикация

1. Убедитесь, что проверка `pylint` в Pull Request успешна.
2. Выполните слияние в `main`.
3. Откройте Actions → Publish documentation.
4. Дождитесь успеха заданий `build` и `deploy`.
5. Откройте URL из окружения `github-pages` и проверьте главную страницу.

## Ручной перезапуск

Для повторной публикации используйте Actions → Publish documentation → Run workflow.
Пустой коммит для этой цели не требуется.

## Диагностика

Определите, где произошёл отказ: в CI, при сборке сайта, загрузке артефакта
или публикации. Затем прочитайте журнал отказавшего шага и устраните причину.
